## 一、项目概述

### 产品定义
一款面向欧洲华人百货批发商的**极速下单工具**，通过自动化技术将传统手动逐条搜索下单的流程压缩到几分钟内完成。

### 核心价值
| 手动下单 | 使用下单神器 |
|---------|------------|
| 100个商品需要30-60分钟 | 100个商品只需2-3分钟 |
| 重复机械操作，容易出错 | 粘贴条码，一键执行 |
| 人必须盯着手机操作 | 自动运行，人可以去做别的事 |

### 一句话描述
**"你还在一个一个搜条码下单？"**

## 二、市场分析

### 目标用户画像
- **身份**：在欧洲（意大利、西班牙、法国、德国等）经营百货店的华人个体户
- **规模**：估计 10,000 - 20,000 人
- **特征**：
  - 使用友购（Yollgo）等 B2B 平台向批发商进货
  - 每次下单几十到几百个商品
  - 大多使用 iPhone
  - 活跃在华人微信群/社群中
  - 对价格敏感但愿意为效率付费
  - 年龄 25-55 岁，中文为主要语言

### 用户痛点
1. **时间浪费** — 每次进货需要手动搜索几十上百个条码，耗时巨大
2. **操作枯燥** — 搜索→加购→搜索→加购，纯机械重复
3. **容易出错** — 手动输入条码容易打错，漏掉商品
4. **频率限制** — 操作太快会被平台弹窗拦截，需要等待

### 市场规模测算
| 指标 | 保守估计 | 乐观估计 |
|------|---------|---------|
| 欧洲华人百货商总数 | 10,000 | 20,000 |
| 使用友购的比例 | 50% | 70% |
| 潜在用户 | 5,000 | 14,000 |
| 愿意付费的比例 | 10% | 20% |
| 可转化付费用户 | 500 | 2,800 |

### 竞争分析
**目前市场上零竞争对手。** 这是一个全新的细分市场，没有任何已知的同类工具。

潜在竞争威胁：
- 友购官方可能开发类似功能（但他们没动力，手动操作=更多页面停留=更多广告曝光）
- 其他开发者可能模仿（但需要了解友购的 DOM 结构，有技术门槛）
- AI 工具降低开发门槛（但用户不会自己开发）

### 竞争壁垒
1. **先发优势** — 第一个做的，用户心智占领
2. **经验积累** — 对友购网页结构和防封控策略的深度了解
3. **云端架构** — 核心逻辑在服务器，即使 app 被逆向也拿不到关键代码
4. **用户粘性** — 一旦用习惯就离不开，切换成本高
5. **快速迭代** — 友购改了网页，你能快速适配，模仿者需要重新研究

## 五、分发策略

### 为什么不上 App Store
1. Apple 审核会拒绝（注入 JS 操作第三方网站违反 2.5.1 条款）
2. 友购一封举报邮件就能让 app 下架
3. 上架后代码公开暴露，被抄袭风险高
4. 审核周期长，更新不灵活

### TestFlight 分发方案（推荐）
- Apple 官方测试分发渠道，合法合规
- 最多 **10,000 名**外部测试用户（足够覆盖市场）
- 不需要通过 App Store 审核（只需基本的 Beta 审核，宽松很多）
- 可以随时推送更新
- 友购无法通过 Apple 渠道举报
- 用户通过邀请链接加入，天然形成封闭圈子
- 每个 build 有效期 90 天，需要定期更新（也是保持用户活跃的机制）

### 用户获取流程
```
看到推广 → 加你微信 → 付款 ¥99 → 你发 TestFlight 邀请链接 + 序列号
→ 用户下载安装 → 输入序列号激活 → 开始使用
```

### 续费流程
```
序列号到期前3天 → App内提示即将到期
→ 用户微信联系你 → 付款 → 你后台执行续费 → 用户继续使用
```

### 未来支付方案（用户量大了以后）
- 接入微信支付/支付宝（通过网页收银台）
- 或 Stripe（支持欧洲信用卡）
- 自动续费，减少人工操作

## 九、技术部署指南

### 服务器部署

**1. 购买 VPS**
- 推荐 Hetzner Cloud（德国，€4.5/月起）
- 或 OVH（法国，€3.5/月起）
- 选 Ubuntu 22.04，1核1G内存够用

**2. 安装 Node.js**
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

**3. 部署验证服务**
```bash
# 上传 server/ 目录到服务器
cd /home/server
npm install
npm start
# 首次运行会打印管理员密钥，请保存！
```

**4. 配置 HTTPS（必须）**
```bash
# 安装 nginx + certbot
sudo apt install nginx certbot python3-certbot-nginx
# 配置域名指向服务器 IP
# 获取 SSL 证书
sudo certbot --nginx -d yourdomain.com
```

**5. 用 PM2 保持运行**
```bash
npm install -g pm2
pm2 start server.js --name license-server
pm2 startup
pm2 save
```

### App 配置

**1. 修改服务器地址**
打开 `LicenseManager.swift` 第 7 行：
```swift
private let serverURL = "https://YOUR-SERVER.com"
// 改成你的实际域名，例如：
private let serverURL = "https://api.yourdomain.com"
```

- Xcode → Product → Archive

- App Store Connect → TestFlight → 添加外部测试组
- 生成公开链接或邮件邀请用户

## 十一、关键指标（KPI）

### 每月跟踪
| 指标 | 说明 | 目标 |
|------|------|------|
| 新增付费用户 | 当月新注册的付费用户数 | 月增长 20%+ |
| 月活用户(MAU) | 当月至少使用1次的用户数 | >80% 的付费用户 |
| 续费率 | 到期用户中续费的比例 | >70% |
| 月流失率 | 当月停止付费的用户比例 | <15% |
| 月收入(MRR) | 当月总收入 | 持续增长 |
| 客服响应时间 | 用户发消息到你回复的时间 | <2小时 |

### 健康标准
- 续费率 > 70% = 产品有价值，用户离不开
- 续费率 50-70% = 还行，需要改进
- 续费率 < 50% = 产品有问题，需要重大调整

## 十二、长期愿景

### 12个月后的可能方向

1. **多平台下单工具**
   - 不只友购，支持欧洲其他华人批发平台
   - 成为"欧洲华人批发商的效率工具箱"

2. **SaaS 化**
   - 从工具变成服务平台
   - 加入库存管理、价格对比、历史订单分析
   - 月费可以提到 €30-50

3. **与友购谈合作**
   - 用户量足够大后，可以主动联系友购
   - 变成官方合作伙伴/官方插件
   - 风险归零，收入可能更高

4. **卖掉**
   - 如果用户量到了1000+，有稳定月收入
   - 对批发商SaaS公司有收购价值
   - 估值通常是年收入的 3-5 倍
